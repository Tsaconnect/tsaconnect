# PM App + Backend Hooks Implementation Plan (Plan 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the PM (Payment Merchant) buy/sell experience usable in the mobile app by reusing the existing P2P trade flow with PM-aware tweaks, and add the operator manual-release queue UI — plus the two small backend hooks the screens need.

**Architecture:** PM trades ARE P2P trades (ad `pm_id` set), so the user-facing flow reuses `/p2p` screens. Two backend additions expose what the screens need: (1) `isPm` + the PM's static Nomba pay-to account on the trade/ad detail (buy screen shows "pay ₦X to this account"); (2) capture the user's payout bank account when opening a *sell* trade to a PM (the live Nomba name-check stays gated). The operator queue is new admin screens mirroring `/admin/p2p-disputes`, calling the already-built `/api/admin/pm/*` endpoints (PM backend Task 7).

**Tech stack:** Backend — Go/Gin/GORM. App — React Native 0.81 + Expo 54 + expo-router v6, TSA Signature design system (`@/theme` + `@/components/ui`), jest.

**Design decisions (approved 2026-06-16):**
- User-facing PM: **reuse the P2P flow + PM tweaks** (not a parallel screen stack).
- Operator queue: **admin-gated, mirror `/admin/p2p-disputes`**.

**Gated (do not block on):** the live Nomba **name-verification** of the user's payout bank account (uses Nomba name-lookup, part of PM Task 9). Build the capture + store now; stub/gate the live verify behind a `// TODO(nomba-facts)`.

**Reference:** PM design spec `docs/superpowers/specs/2026-06-15-pm-payment-merchant-design.md` (§3 App, §5 buy, §6 sell). App surface map: see the P2P pattern in `tsa-app/app/p2p/trade/[tradeId].tsx`, `app/p2p/ad/[adId].tsx`, `app/admin/p2p-disputes*`, API client `tsa-app/services/p2p.ts`, role gate `tsa-app/hooks/useUserRole.ts`.

## Task A4 (app): operator manual-release queue

**Files:** `app/admin/pm-queue.tsx` (new), `app/admin/pm-queue/[tradeId].tsx` (new), `services/p2p.ts` (`pmAdminApi`).

Mirror `app/admin/p2p-disputes.tsx` + `[tradeId].tsx`, role-gated via `useUserRole` (ADMIN_ROLES). Add to `services/p2p.ts`:
```ts
export const pmAdminApi = {
  manualQueue: () => get('/admin/pm/manual-queue'),
  release: (tradeId) => post(`/admin/pm/trades/${tradeId}/release`, {}),
  decline: (tradeId) => post(`/admin/pm/trades/${tradeId}/decline`, {}),
  payout:  (tradeId) => post(`/admin/pm/trades/${tradeId}/payout`, {}),
};
```
(match the existing auth-header + idempotency-key pattern in `p2p.ts`.)
